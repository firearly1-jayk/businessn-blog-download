# 사업n 블로그 자동화 — 내려받기

사업n 블로그 자동화 프로그램을 내려받는 곳이에요. 여기에는 프로그램 파일만 있어요.

## 처음 설치

| 내 컴퓨터 | 내려받기 |
| --- | --- |
| 윈도우 | [윈도우용](https://github.com/firearly1-jayk/businessn-blog-download/releases/latest/download/businessn-blog-windows-x64.zip) |
| 맥 (애플칩 M1~M5) | [맥 애플칩용](https://github.com/firearly1-jayk/businessn-blog-download/releases/latest/download/businessn-blog-macos-arm64.zip) |
| 맥 (인텔) | [맥 인텔용](https://github.com/firearly1-jayk/businessn-blog-download/releases/latest/download/businessn-blog-macos-x86_64.zip) |

**윈도우**
1. 받은 ZIP을 오른쪽 클릭 → [압축 풀기]를 누르고, `C:\blog`처럼 짧은 곳에 풀어요.
2. `사업n - 블로그 자동화 v01.exe`를 실행해요. "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행]을 눌러요.

**맥**
1. 애플 메뉴 → 이 Mac에 관하여에서 칩을 확인해요. "Apple M…"이면 애플칩용, "Intel"이면 인텔용이에요.
2. ZIP을 더블클릭해 풀고, 앱을 '응용 프로그램' 폴더로 옮겨요.
3. 앱을 열어요. 경고가 뜨면 [완료]를 누른 뒤 시스템 설정 → 개인정보 보호 및 보안 → [그래도 열기]를 눌러요.

## 업데이트

설치한 뒤에는 앱이 새 버전을 스스로 찾아요. '새 버전이 나왔어요'에서 [지금 업데이트]만 누르면 돼요.
글·일정·설정은 그대로 남아요.

## 자주 묻는 질문

**업데이트는 어떻게 하나요?**
앱을 켜 두면 새 버전을 스스로 찾아요. "새 버전이 나왔어요" 창에서 [지금 업데이트]를 마우스로 누르면 돼요.
앱이 잠깐 닫혔다가 새 버전으로 다시 켜져요. 직접 확인하려면 [설정] → [업데이트 확인]을 눌러요.

**업데이트하면 글·일정·설정이 사라지나요?**
아니요. 글·일정·설정과 쿠폰 등록은 그대로 남아요. 앱 프로그램만 바뀌어요.

**[나중에]를 눌렀어요. 다시 하려면요?**
화면 오른쪽 위 [설정] 옆의 초록색 '새 버전' 표시를 누르거나, [설정] → [업데이트 확인]을 눌러요.

**[지금 업데이트]가 눌리지 않아요.**
마우스로 눌러 주세요. 엔터 키로는 눌리지 않아요.
예약·글·카드 만들기 같은 일을 하는 동안에는 잠겨 있어요. 일이 끝나면 저절로 풀려요.
다른 창이 열려 있어도 잠겨요. 그 창을 닫아 주세요.

**[설정] 메뉴에 [업데이트 확인]이 없어요.**
업데이트 기능이 없는 예전 버전이에요. 위 '처음 설치'대로 새 파일을 한 번만 받아 주세요.
- 윈도우: 사업n을 끄고 쓰던 폴더를 통째로 백업해요. 새 ZIP을 풀어 나온 exe 파일, `_internal` 폴더, `시작하기.txt`를 쓰던 폴더에 덮어써요. 쓰던 폴더의 `user_data` 폴더와 `config.ini` 파일은 지우지 마세요. 글·일정·설정이 여기에 있어요.
- 맥: 사업n을 끄고 새 앱을 '응용 프로그램' 폴더로 옮겨요. 같은 이름이 있다고 하면 [대치]를 눌러요. 글·일정·설정은 그대로 남아요.

**"자동 업데이트를 쓸 수 없어요"가 떠요.**
- 윈도우: ZIP을 먼저 풀고, 프로그램 폴더를 `C:\blog`처럼 이 PC 안의 폴더에 두세요. 바탕 화면·OneDrive·NAS·Program Files는 피해 주세요. 옮길 때는 사업n을 끄고 폴더를 통째로 옮겨요(`user_data`·`config.ini` 포함).
- 맥: 앱을 '응용 프로그램' 폴더로 옮긴 뒤 거기서 켜 주세요.

**"업데이트하지 못했어요"가 떠요.**
지금은 예전 버전으로 그대로 쓸 수 있어요. 인터넷 연결과 저장 공간(500MB 이상)을 확인해 주세요.
윈도우에서는 백신이 막는 경우가 많아요. 백신 검사 예외에 프로그램 폴더를 넣은 뒤 [설정] → [업데이트 확인]으로 다시 해 주세요.

**"받은 업데이트가 사업n 정품과 달라 설치하지 않았어요."가 떠요.**
여러 번 누르지 말고 문의해 주세요. 다른 곳에서 받은 파일은 설치하지 마세요.

**문의할 때 무엇을 보내면 되나요?**
화면에 보인 문장 그대로, 그리고 기록 파일을 보내 주세요.
[설정] → [문의용 기록 폴더 열기]를 누르면 폴더가 열려요. 그 안의 `app.log` 파일을 보내 주세요.
API 키나 비밀번호는 보내지 마세요.
